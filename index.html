Opening Linnet the first time

Linnet is so new that your computer doesn’t know it yet, so it asks you once to be sure. After that it opens like any other app.

On a Mac

About a minute, once.

  1. Open the file you downloaded (it ends in .dmg). A small window appears.
  2. Drag the Linnet bird onto the Applications folder.
  3. Open Applications and double-click Linnet. Your Mac will say it can’t check the app. Click Done (or OK).
  4. Open System Settings, then Privacy & Security. Scroll down and click Open Anyway next to Linnet, then confirm with your password.
  5. Linnet opens. From now on it opens normally.

You can eject the Linnet disk on your desktop once it’s in Applications.

It says Linnet “is damaged”

That’s the same check being extra cautious. Open Terminal (in Applications, then Utilities), paste this line and press Return, then open Linnet again:

xattr -cr /Applications/Linnet.app

On Windows

About a minute, once.

  1. Open the file you downloaded (it ends in setup.exe).
  2. If a blue box says Windows protected your PC, click More info, then Run anyway.
  3. Follow the installer. It only takes a few seconds.
  4. Linnet opens. You’ll find it in the Start menu from now on.

If your browser asks whether to keep the download, choose Keep.

Linnet updates itself. When a new version is ready you’ll see a small blue dot on the Menu.
